# dm-all

Un solo sitio para todos los reportes de INMONTE. La página principal (`index.html`) permite cambiar entre reportes con una transición suave; cada reporte se carga una vez y se mantiene abierto, así conserva sus filtros al ir y volver.

| Reporte | Archivo | Origen |
|---|---|---|
| Supply chain y operaciones | `reports/supply/index.html` | `github-supply/index.html` (repo `dm-supply`) |
| Fletes 2026 | `reports/fletes/fletes-report.html` | `github-fletes/dm-fletes/fletes-report.html` (repo `dm-fletes`) |
| Gastos 2026 | `reports/gastos/index.html` | `dm-cotizador/dm-cotizador/index.html` |
| Publicidad, marketing y atención a clientes | `reports/publicidad/index.html` | `dm-publicidad/index.html` |
| Cotizador de compras | `reports/cotizador/index.html` | `dm-cotizador/index.html` |

Los archivos de `reports/` son copias exactas de los originales, sin cambios.

Atajos: teclas `1`–`5` abren cada reporte y `0` vuelve al inicio. Cada reporte también tiene su propio enlace, por ejemplo `#fletes`.

Publicado con GitHub Pages desde la rama `main`.
